# Security Policy

[简体中文](#简体中文)

## Reporting a vulnerability

If you find a security issue in iterx — for example leaked credentials, a bypass of flash or download verification, or broken access control in the community or account services — **please do not open a public issue**.

Report it privately through GitHub (repository → **Security** → **Report a vulnerability**), or reach the team at [iterx.ai/contact](https://www.iterx.ai/contact).

Please include the affected component and version, steps to reproduce, and the potential impact. We will reply after confirming the report, fix it, and disclose details once the fix is released.

## Supported versions

Security fixes land in the latest release of each package. Please upgrade before reporting, e.g. `npm i -g @iterx/cli@latest`.

## 简体中文

如果你发现 iterx 的安全漏洞（例如凭据泄露、烧录或下载校验被绕过、社区或账号服务越权），**请不要公开提 issue**。请通过 GitHub 私密漏洞报告（仓库 → Security → Report a vulnerability）提交，或经 [iterx.ai/contact](https://www.iterx.ai/contact) 联系团队，并附上影响的组件与版本、复现步骤和影响范围。我们确认后会尽快修复，修复发布后再公开细节。安全修复只发布在各包的最新版本，报告前请先升级。
