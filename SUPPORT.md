# Getting Help

[简体中文](#简体中文)

- **Something broke?** Run `iterx doctor --json` first — every failed check comes with a `fix`.
- **Usage questions and build ideas**: ask in the [iterx community](https://community.iterx.ai).
- **Bugs and feature requests**: open an issue in the matching repository using the templates.
- **Service down?** Check [iterx.ai/status](https://www.iterx.ai/status).
- **Business, education or partnership**: [iterx.ai/contact](https://www.iterx.ai/contact).

## 简体中文

- **出问题了？** 先运行 `iterx doctor --json`，每个失败项都附带修复方法 `fix`。
- **使用问题与作品点子**：到[词元开物社区](https://community.iterx.ai)提问。
- **Bug 与功能建议**：在对应仓库按模板开 issue。
- **服务不可用？** 查看 [iterx.ai/status](https://www.iterx.ai/status)。
- **商务、教育与合作**：[iterx.ai/contact](https://www.iterx.ai/contact)。
